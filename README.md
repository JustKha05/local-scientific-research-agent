# Local Scientific Research Agent with Evidence Verification

A local research assistant for scientific paper question answering
and claim verification with traceable evidence.

## Project status

Phase 1: environment setup and local inference smoke test.

## Initial scope

- English scientific text.
- Paper QA using QASPER.
- Claim verification using SciFact.
- Local inference through Ollama.
- Evidence-linked answers and claim-level verification.
